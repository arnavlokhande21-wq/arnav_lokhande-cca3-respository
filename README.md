## Project Title
**Usability Study: Original Air India Website vs. Redesigned Flight-Booking Prototype**

## Project Overview
This project evaluates the usability of the original Air India flight-booking website and compares it with a redesigned interactive prototype created in Figma. The objective is to identify usability issues and explore how a simpler interface can make flight booking easier to understand and navigate.

## Figma Prototype
**Prototype link:** https://www.figma.com/make/fmMZvAPCmZ9qg9uVS53yuK/Flight-booking-app?p=f&t=FZWaKOQVocL5crCf-0

## Methodology
- Conducted usability testing with five participants.
- Asked participants to complete the same flight-booking task on the original website and the redesigned prototype.
- Used think-aloud interviews to understand participants' experiences.
- Collected qualitative feedback and UX survey responses.
- Reviewed interview transcripts to identify recurring usability themes.

## Key Findings
1. The original website could feel cluttered because promotions and upgrade prompts competed for attention.
2. Participants generally described the redesigned prototype as cleaner, more focused, and easier to navigate.
3. Clearer actions, such as **Continue** and **Confirm Booking**, helped communicate the next step.
4. Passenger categories, including adult, child, and senior, could be made more explicit.
5. Fare comparisons should remain clear while avoiding unnecessary distractions.

## Conclusion
The usability study suggests that a cleaner layout, clearer navigation, and fewer distracting prompts can improve the perceived usability of the flight-booking experience. Further testing with more participants and quantitative survey analysis would help validate these findings.
